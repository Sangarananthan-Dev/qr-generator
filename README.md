# 📱 Minimal QR Code Generator

A clean, minimal QR code generator with custom logo overlay support matching Midfin360 styling.

---

## ✨ Features

- 🔗 **URL Input**: Enter any destination URL.
- 🖼️ **Logo Upload**: Upload custom logo with center rounded badge and corner clipping.
- ⚡ **Instant / One-Click Generate**: High-resolution 512×512 QR code with Error Correction Level `H` (30%).
- 💾 **Download PNG**: Direct one-click download for high-quality PNG.

---

## 🛠️ Quick Start

```bash
git clone https://github.com/Sangarananthan-Dev/qr-generator.git
cd qr-generator
npm install
npm run dev
```
